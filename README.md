# Kacha Haus — จอในร้าน

หน้าตัวอักษรวิ่งแบบป้าย LED สำหรับจอ MagicPlayer ในร้าน Kacha Haus

**ลิงก์จอ:** https://xkaebii.github.io/kacha-haus-screen/ (ใส่ในแอพ LedArt → Web Page)

## เปลี่ยนสิ่งที่ขึ้นจอ (จากที่ไหนก็ได้)
แก้ไฟล์ `config.json` (บนมือถือ: แอพ GitHub → repo นี้ → config.json → ✏️ → Commit) · GitHub Pages อัปเว็บใน ~1 นาที แล้วจอเช็กค่าใหม่ทุก 1 นาที เปลี่ยนเองแบบค่อยๆ จาง

- `mode`: `led` ตัวอักษรวิ่ง · `image` รูปเต็มจอ (ใส่ลิงก์รูปใน `image`, `fit` = `cover` เต็มจอ / `contain` เห็นทั้งรูป) · `black` จอดำ
- `rows`: หนึ่งบรรทัด = หนึ่งแถว · ใส่ `*` หน้าคำ = ตัวทึบ คำอื่นเป็นตัวโปร่ง (ฟอนต์มีแค่ภาษาอังกฤษ)
- `bg` / `fg` สีพื้น / ตัวอักษร · `angle` มุมเอียง · `size` ขนาดตัว (% ของด้านสั้นจอ) · `speed` ความเร็ว · `logo` `true` / `false`
- `logoX` / `logoY` ขยับโลโก้ (% ของความกว้าง / สูงจอ, ติดลบ = ซ้าย / ขึ้น) · `logoSize` ขนาดโลโก้ (% ของด้านสั้นจอ, ปกติ 50)
- `guides`: `true` = โชว์เส้นกลางจอ + ขอบ + ขนาดหน้าจอที่เบราว์เซอร์เห็น (ไว้เช็กตำแหน่ง) · ปกติ `false`
- เพิ่ม `version` ทุกครั้งที่แก้ · เปิดลิงก์ต่อท้าย `?debug=1` จะเห็นเลข version ที่จอใช้อยู่มุมขวาล่าง
- ต้องเป็น JSON ที่ถูกต้อง (มี `,` คั่น, ใช้ `"` ) ถ้าไฟล์พัง จอจะโชว์ของเดิมต่อ

## ไฟล์
- `index.html` สร้างจาก `template.html` ด้วย `python3 build.py` (ฝังโลโก้จาก `logo.svg`)
- จอรีโหลดตัวเองทุก 6 ชม. · เน็ตหลุดจะโชว์ของเดิมต่อ
- ทดสอบค่าทาง URL ได้ เช่น `?mode=led&angle=-30&bg=15152a`
